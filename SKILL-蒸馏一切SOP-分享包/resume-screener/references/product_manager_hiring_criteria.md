# 产品经理招聘标准（占位模板）

> 本文件为占位模板，正式使用前请替换为贵公司真实的产品经理招聘标准。
> 下方各评分项默认采用 0-5 分制：0 = 完全不符，3 = 基本符合，5 = 突出。
> 模型评估时会逐条对照简历内容打分，并在 evidence 中写明依据。

## 评分项（默认每项满分 5 分）

### 1. 用户洞察与需求分析能力
考察是否具备用户研究、客户访谈、竞品分析、需求拆解与优先级判断能力，能否从业务目标和用户场景中提炼真实问题。

### 2. 产品规划与方案设计能力
考察是否有从 0 到 1 或从 1 到 N 的产品规划经验，能否输出清晰的产品路线图、PRD、原型、流程设计和功能方案。

### 3. 项目推进与跨团队协作能力
考察是否能协调研发、设计、运营、销售、市场等角色推进项目落地，是否具备里程碑管理、风险识别和问题闭环能力。

### 4. 数据分析与业务结果导向
考察是否能定义并跟踪产品指标，使用数据分析发现问题、验证假设、评估上线效果，并能用可量化结果说明产品贡献。

### 5. 行业理解与商业敏感度
考察对目标行业、商业模式、客户价值链、竞争格局和增长机会的理解，是否能把产品决策与业务收益关联起来。

### 6. 表达能力与产品文档质量
考察简历中体现的结构化表达、汇报沟通、文档撰写、原型说明和需求传递能力，是否能让复杂问题被团队准确理解。

## 加分项

- 有完整负责核心产品模块、商业化产品、平台型产品或 B 端复杂业务系统的经验。
- 有明确可验证的业务成果，例如转化率、留存率、GMV、收入、效率、成本或满意度改善。
- 熟悉常用产品工具和数据工具，如 Figma、Axure、墨刀、SQL、Excel、BI 工具等。
- 有 AI、SaaS、电商、内容、汽车、旅游、本地生活、企业服务等目标行业经验。
- 有技术背景、设计背景、运营增长背景或一线客户成功 / 销售协作经验。

## 风险项

- 简历只描述功能清单，缺少个人角色、决策依据、落地过程或结果数据。
- 项目经验偏执行，缺少需求判断、方案取舍、指标定义或复盘能力体现。
- 频繁跳槽且每段产品经历时间较短，缺少完整产品周期经验。
- 过度依赖主观描述，缺少案例、数据、用户反馈或业务结果支撑。
- 与目标岗位行业、产品类型或用户群体差异过大，迁移能力证据不足。

## 结论判定参考（总分满分 30）

| 总分区间 | 结论 |
|----------|------|
| 24-30 | 推荐进入面试 |
| 18-23 | 备选 |
| 0-17 | 不推荐 |

> 上述阈值仅为示例，请按公司实际标准调整。
