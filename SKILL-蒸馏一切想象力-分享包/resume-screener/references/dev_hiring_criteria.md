# 开发人员招聘标准（占位模板）

> 本文件为占位模板，正式使用前请替换为贵公司真实的开发人员招聘标准。
> 下方各评分项默认采用 0–5 分制：0 = 完全不符，3 = 基本符合，5 = 突出。
> 模型评估时会逐条对照简历内容打分，并在 evidence 中写明依据。

## 评分项（默认每项满分 5 分）

### 1. 编程语言与技术栈匹配度
考察简历中掌握的语言 / 框架与岗位要求的契合度（如 Java、Python、Go、React 等）。

### 2. 项目经验与复杂度
考察参与项目的规模、角色、技术难点与个人贡献，是否包含可量化的成果。

### 3. 系统设计与架构能力
考察是否有架构设计、高并发 / 高可用 / 分布式相关经验或案例。

### 4. 工程素养
考察代码规范、测试习惯、CI/CD、代码评审、文档撰写等工程实践经历。

### 5. 学习能力与技术深度
考察对底层原理的掌握、技术博客 / 开源贡献 / 专利 / 论文等。

### 6. 教育背景与基础
考察学历层次、计算机相关专业背景、数据结构 / 算法等基础扎实程度。

## 结论判定参考（总分满分 30）

| 总分区间 | 结论 |
|----------|------|
| 24–30 | 推荐进入面试 |
| 18–23 | 备选 |
| 0–17 | 不推荐 |

> 上述阈值仅为示例，请按公司实际标准调整。
